# Portfolio de Landings Web

Colección de landing pages y mini-proyectos para portafolio de GitHub. Cada carpeta es un proyecto independiente con su propio stack y scripts.

## Proyectos

- `01-agency-next` — Agencia digital creativa (Next.js 14 + Tailwind). Dark + candy/aqua. Bilingüe ES/EN.
- `02-saas-next` — SaaS de productividad "Flowboard" (Next.js 14 + Tailwind). Features, pricing, FAQ, testimonios.
- `03-restaurante` — Restaurante "La Brasa" (HTML + Tailwind CDN). Menú, galería, reservas.
- `04-gimnasio` — Gimnasio "IronForge" (HTML + Tailwind CDN). Programas, planes, entrenadores.
- `05-inmobiliaria` — Bienes raíces "Altura Homes" (HTML + Tailwind CDN). Catálogo de propiedades.
- `06-evento` — Conferencia tech "DevConf 2026" (HTML + Tailwind CDN). Speakers, agenda, tickets.
- `07-producto-react` — Audífonos "Aether H1" (React + Vite + Tailwind). Selector de color, carrito.
- `08-portfolio-next` — Portafolio personal del desarrollador (Next.js 14 + Tailwind). Proyectos, skills, experiencia, blog.
- `09-cafe` — Cafetería "Origen Café" (HTML + Tailwind CDN). Menú, orígenes, sucursales.
- `10-travel` — Agencia "Nomad Routes" (HTML + Tailwind CDN). Destinos, paquetes, cotizador.
- `11-academy` — Academia "SkillStack" (HTML + Tailwind CDN). Cursos, planes, instructores.
- `12-clinic` — Clínica "NovaClinic" (HTML + Tailwind CDN). Servicios, doctores, citas.
- `13-java-biblioteca` — App de consola en Java (POO + estructuras de datos: ArrayList, HashMap, Queue, Stack, HashSet; Merge Sort y Binary Search). Interfaz ES/EN.
- `14-python-logistics` — App de consola en Python (POO + grafo y Dijkstra, BFS, Merge Sort, Binary Search, tests con unittest). Interfaz ES/EN.

## Cómo ejecutar

Proyectos HTML: abre `index.html` en el navegador (o usa Live Server).

Proyectos Next.js:
```bash
cd 01-agency-next   # o 02-saas-next, 08-portfolio-next
npm install
npm run dev
```

Proyecto React + Vite:
```bash
cd 07-producto-react
npm install
npm run dev
```
