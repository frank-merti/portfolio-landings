Travel agency landing: destinations, packages and a quote request form with ES/EN switch.

**Landing de agencia de viajes: destinos, paquetes y formulario de cotización con cambio ES/EN.**

---

## ES

### Funcionalidad
- Hero centrado con métricas (destinos, viajeros, satisfacción, años).
- Grid de 4 destinos con precio desde.
- Tres paquetes (escapada, aventura, premium) con el destacado escalado.
- Formulario de cotización con selección de destino y confirmación.
- Conmutador ES/EN con persistencia en `localStorage`.

### Stack
HTML5 semántico · Tailwind CSS (CDN) · JavaScript vanilla · CSS Grid

### Ejecutar
```bash
cd 10-travel
npx serve 10-travel
```

### Qué aprendí
- Un hero centrado con doble CTA y métricas genera confianza más rápido que uno alineado a la izquierda.
- Los precios "desde" comunican ranged pricing sin esconder el valor real de cada paquete.
- Un formulario corto (4 campos) convierte mejor que uno largo en landings de captación.

## EN

### Features
- Centered hero with metrics (destinations, travelers, satisfaction, years).
- Grid of 4 destinations with "from" pricing.
- Three packages (getaway, adventure, premium) with the highlighted one scaled.
- Quote request form with destination picker and confirmation state.
- ES/EN switch persisted in `localStorage`.

### Stack
Semantic HTML5 · Tailwind CSS (CDN) · Vanilla JavaScript · CSS Grid

### Run
```bash
cd 10-travel
npx serve 10-travel
```

### What I learned
- A centered hero with dual CTA and metrics builds trust faster than a left-aligned one.
- "From" pricing communicates range without hiding the real package value.
- A short form (4 fields) converts better than a long one on lead-generation landings.
