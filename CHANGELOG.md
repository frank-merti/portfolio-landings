# Changelog

All notable changes to this portfolio are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- `15-taskboard-fullstack` — Next.js 14 + Prisma + SQLite + auth + Vitest (in progress)

### Changed
- Portfolio moved to a single monorepo with one release and one Pages deployment

## [1.1.0] - 2026-10-20

### Added
- Java console application: OOP, Merge Sort, binary search, FIFO queue and LIFO undo stack
- Python console application: Dijkstra, BFS, Merge Sort, binary search and priority queue
- Unit tests for the Python algorithms module
- ES/EN language switch for both console applications
- Root `index.html` showcase deployed as the GitHub Pages landing page
- `robots.txt` and `sitemap.xml` for the deployed site

### Changed
- Code style standardized: identifiers in English, user-facing copy externalized
- All projects now ship a bilingual README and a `LICENSE` file

## [1.0.0] - 2026-10-14

### Added
- 8 landing pages: agency, SaaS, restaurant, gym, real estate, conference, product launch and personal portfolio
- GitHub Actions workflow that builds and deploys the site to GitHub Pages
