**Landing de academia online: catálogo de cursos, planes de suscripción, instructores y cambio ES/EN.**

---

## ES

### Funcionalidad
- Hero con degradado violeta y métricas (cursos, estudiantes, rating).
- Catálogo de 6 cursos con duración y valoración.
- Tres planes (básico, pro, empresa) con el destacado escalado.
- Grid de instructores con especialidad.
- Conmutador ES/EN con persistencia en `localStorage`.

### Stack
HTML5 semántico · Tailwind CSS (CDN) · JavaScript vanilla · CSS Grid

### Ejecutar
```bash
cd 11-academy
npx serve 11-academy
```

### Qué aprendí
- En productos digitales, mostrar duración y rating por curso reduce la fricción antes del pricing.
- Reutilizar un mismo patrón de "tarjeta destacada" entre proyectos acelera la producción y mejora la consistencia.
- Un catálogo con metadatos (horas, estrellas) se lee mejor con tipografía monoespaciada en los datos numéricos.

## EN

### Features
- Hero with violet gradient and metrics (courses, students, rating).
- Catalogue of 6 courses with duration and rating.
- Three plans (basic, pro, enterprise) with the highlighted one scaled.
- Instructor grid with specialties.
- ES/EN switch persisted in `localStorage`.

### Stack
Semantic HTML5 · Tailwind CSS (CDN) · Vanilla JavaScript · CSS Grid

### Run
```bash
cd 11-academy
npx serve 11-academy
```

### What I learned
- For digital products, showing duration and rating per course reduces friction before pricing.
- Reusing a "highlighted card" pattern across projects speeds up delivery and improves consistency.
- A catalogue with metadata (hours, stars) reads better with numeric data in a distinct type style.
